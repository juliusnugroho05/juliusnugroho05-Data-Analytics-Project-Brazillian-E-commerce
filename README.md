# E-Commerce Data Analysis: Brazil Olist

This project was developed as part of the Data Analytics course project within the Computer Science program (Database Technology specialization) at BINUS University Alam Sutera. 

This project analyzes an end-to-end e-commerce dataset from Olist, a major e-commerce platform in Brazil that connects buyers and sellers. The dataset encompasses the entire transaction lifecycle, including order placements, product pricing, payment methods, logistics/delivery details, and customer reviews.

Due to the massive scale of the primary dataset and computational constraints, a randomized sampling method was implemented to extract a representative subset of 10,000 transactions for efficient analysis without losing statistical accuracy.

The analytical approach focuses on two primary phases:

Descriptive Analytics: To understand historical patterns and transaction behaviors, such as identifying customer purchasing trends and the distribution of preferred payment methods.
Diagnostic Analytics: To uncover the root causes of specific operational friction points, primarily investigating how delivery delays correlate with low customer satisfaction review scores.
