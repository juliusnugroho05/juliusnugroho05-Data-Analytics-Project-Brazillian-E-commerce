# E-Commerce Data Analysis: Brazil Olist

This project was completed as part of a data analytics course, analyzing customer satisfaction patterns on a Brazilian e-commerce platform using the Olist dataset. Converting raw transactional data into valuable insights to support data informed decision making.

All detail of the project can be accesed from [Notion](https://app.notion.com/p/E-Commerce-Data-Analysis-Brazil-Olist-3670155f99b3802a9412d81487edb06d).
